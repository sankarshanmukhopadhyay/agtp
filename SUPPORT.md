# Support

Use GitHub Issues for reproducible defects, documentation problems, interoperability questions, and bounded feature proposals. Include the affected revision, expected and observed behaviour, and the smallest useful reproduction or evidence reference.

Security vulnerabilities must follow [`SECURITY.md`](SECURITY.md) and must not be disclosed publicly before remediation.

This repository is maintained as an implementation/adaptation surface. Questions about upstream normative intent should be routed to the relevant upstream authority; repository-local answers do not redefine upstream semantics.
