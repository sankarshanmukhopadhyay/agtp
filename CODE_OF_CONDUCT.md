# Code of Conduct

Participation in this project requires professional, respectful, and good-faith collaboration.

Contributors must not harass, threaten, discriminate against, or deliberately intimidate other participants. Technical disagreement is expected; critique should address claims, evidence, implementation, and governance consequences rather than individuals.

Maintainers may remove content or restrict participation when behaviour materially undermines a safe and productive project environment. Serious concerns should be raised privately with the repository maintainer rather than escalated through public argument.
